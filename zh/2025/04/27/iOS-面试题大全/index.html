基础概念题

什么是 iOS “应用瘦身”？实现方式有哪些？

“应用瘦身”​（App thinning）是美国苹果公司自iOS 9发布的新特性，它能对Apple Store和操作系统进行优化，它根据用户的具体设备型号，在保证应用特性完整的前提下，尽可能地压缩和减少应用程序安装包的体积，也就是尽可能减少应用程序对用户设备存储空间的占用，从而减小用户下载应用程序的负担。

App thinning的实现主要有以下3种方法：

  • Slicing：Apple Store 在应用发布后会根据用户目标设备型号自动生成精简版应用变体，仅包含必要资源，从而减少下载体积并提升效率。
  • Bitcode：Bitcode 是 iOS 开发中的一个可选编译选项。当启用 Bitcode 时，苹果会对编译后的应用二进制文件进行二次优化，将其转换为中间代码（Bitcode），在 Apple Store 上进行编译和链接。这种优化技术可以提升应用的性能和效率。然而，由于许多第三方库不支持 Bitcode，开发者可能需要关闭该选项以确保程序的正常运行。
  • On-Demand Resources：按需供给的资源加载方式是一种动态加载资源的策略，应用程序在运行时根据需要从服务器下载资源，而不是在初始下载时加载所有资源。这种方式可以显著减少初始下载体积和内存占用，特别是在资源密集型应用（如游戏）中效果显著。通过仅在需要时加载资源，应用程序可以更高效地利用内存，并在后台自动删除不常用的资源以释放内存空间。

什么是Cocoa和Cocoa Touch？Cocoa Touch的底层技术架构是什么?

Cocoa和Cocoa Touch是苹果公司Two Sigma Inc.（Two Sigma）开发并维护的开源框架，用于在macOS和iOS设备上开发跨平台软件。

Cocoa Touch是Cocoa的扩展，专门为iOS设备而设计。它提供了一组用于创建iOS应用程序的API，包括用户界面、图形、音频、网络、存储等。Cocoa Touch提供了许多用于处理用户交互、动画、图像处理、网络请求等功能的类和协议。

Cocoa是苹果公司开发并维护的开源框架，用于在macOS上开发跨平台软件。它提供了一组用于创建macOS应用程序的API，包括用户界面、图形、音频、网络、存储等。Cocoa提供了许多用于处理用户交互、动画、图像处理、网络请求等功能的类和协议。

Cocoa Touch和Cocoa的区别是：Cocoa Touch是Cocoa的扩展，专门为iOS设备而设计。Cocoa Touch提供了许多用于处理用户交互、动画、图像处理、网络请求等功能的类和协议。Cocoa Touch的API更适合iOS设备，而Cocoa则更适合macOS。

Cocoa Touch的底层技术架构是：

  • Cocoa Touch 框架层：UI处理、触摸处理、事件驱动、系统接口
  • Media 媒体层：音视视频播放、动画、2D和3D图形
  • Core Service：核心服务层、底层特性、文件、网络、位置服务等
  • Core OS 系统层：内存管理、底层网络、硬件管理

什么是iOS的谓词？

谓词（NSPredicate）是 Objective-C 中用于数据筛选的核心类。它通过逻辑表达式对数组或集合中的元素进行过滤，类似于数据库中的 SQL 查询条件。NSPredicate 可以使用类函数 predicateWithFormat 进行初始化，支持 KeyPath 查询、子查询、聚合函数（如 @avg、@sum）以及多条件组合，从而高效地实现数据的筛选与计算。

什么是响应者链？

响应者链是 iOS 事件处理的核心机制，它由一系列响应者对象按特定规则组成。其核心作用是确定事件传递路径，确保事件被合适对象处理，同时提供事件分发和重定向机制。当一个事件发生时，它从第一个响应者开始传递，如果该对象不能处理事件，事件会沿着链传递到下一个响应者，直到被处理或到达链的末端（UIApplication）。

一个事件响应者的完成主要经过两个过程：hitTest方法命中视图和响应者链确定响应者。hitTest方法首先从顶部UIApplication往下调用（从父类到子类）​，直到找到命中者，然后从命中者视图沿着响应者链往上传递寻找真正的响应者。

什么是“懒加载”？

懒加载（Lazy Loading）是一种通过延迟初始化对象或资源来优化性能和资源消耗的编程模式。其核心思想是​​“按需加载”​​，即仅在真正需要时才实例化或加载相关对象，而非在程序启动或初始化阶段一次性完成。

懒加载实现方式：重写属性的getter方法。

懒加载的缺点：破坏了getter方法的纯洁性，使getter方法过于复杂。

什么是类工厂方法？

简单地说，类工厂方法就是用来快速创建对象的类方法，它可以直接返回一个初始化好的对象。UIKit中最典型的类工厂方法就是UIButton的buttonWithType类工厂方法，开发者使用这个方法指定按钮的类型就可以快速得到一个该类型的初始化好的按钮实例对象。

App ID和Bundle ID有什么不同？

App ID 和 Bundle ID 的主要区别在于：App ID 是一个组合字符串，用于标识开发团队和应用程序，而 Bundle ID 是开发者自定义的应用唯一标识符。App ID 包含开发团队的 ID 和 Bundle ID，两者之间用点分隔。Bundle ID 在 Xcode 中可以查看和设置，但一旦定义就不能修改。
